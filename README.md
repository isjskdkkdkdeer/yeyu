# 夜语 · DạNgữ | Noctis Private Chat

中越翻译聊天，单文件网页版。CSS 和原生 JavaScript 均已内嵌，无需构建或配置后端。

## 上线地址

https://isjskdkkdkdeer.github.io/yeyu/

## 说明

- 放到 GitHub Pages 所选发布分支的根目录即可使用。
- 云翻译默认关闭（GitHub Pages 没有翻译接口），页面用本地演示翻译；要接后端时用 `TranslationEngine.enableCloud(true)` 打开。
- 真通话需要另外接通话适配器（`CallManager.configure`），见页面源码注释。
